
# **Workspace Staff Manager**

Une application web interactive permettant de gérer visuellement le personnel d’une entreprise sur un plan d’étage.
Le projet est conçu pour offrir une expérience fluide, moderne et responsive, tout en respectant des règles métier liées aux rôles et aux zones autorisées.

---

## 🚀 **Fonctionnalités principales**

* Gestion complète du personnel :
  
  ➤ Ajouter, déplacer, supprimer des employés
  
  ➤ Interface “Unassigned Staff” pour le personnel non assigné
  
  ➤ Modale d’ajout avec : Nom, Rôle, Photo (URL), Email, Téléphone et Expériences dynamiques
  
  ➤ Prévisualisation de la photo

  

* Visualisation du plan d’étage avec 6 zones :
  
  ➤ Salle de conférence
  
  ➤ Réception
  
  ➤ Salle des serveurs
  
  ➤ Salle de sécurité
  
  ➤ Salle du personnel
  
  ➤ Salle d’archives

  
  

* Assignation intelligente :
  
  ➤ Réception → Réceptionnistes
  
  ➤ Salle des serveurs → Techniciens IT
  
  ➤ Salle de sécurité → Agents de sécurité
  
  ➤ Managers → Accès à toutes les zones
  
  ➤ Nettoyage → Accès à toutes les zones sauf Archives
  
  ➤ Autres rôles → Accès libre sauf zones restreintes
  
  ➤ Bouton "+" pour ajouter un employé dans une zone
  
  ➤ Bouton "X" pour retirer un employé

  
  

* Profil détaillé d’un employé : photo grand format, coordonnées, rôle, expériences, localisation actuelle.

* Limitation du nombre d’employés par zone.

* Zones vides obligatoires visibles en rouge pâle (sauf salle de conférence + salle du personnel).
